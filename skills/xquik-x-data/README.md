# xquik-x-data

Agent skill for using Xquik as a source-checked X data API and remote MCP
integration.

## Triggers

Use this skill when the user asks to:

- set up Xquik REST API or MCP access
- search X posts or look up users
- export followers, engagement, media, or other X datasets
- create monitors, webhooks, giveaway draws, or other persistent workflows
- plan a confirmation-gated account action
